Datenschutzhinweise

Für dein Konto speichern wir E-Mail-Adresse, Anzeigename, Rolle, Freigabestatus und Tierpräferenzen in Supabase. Bei Vermittlungen kommen Name und Ort der Organisation hinzu. Administratoren können dein Konto freigeben oder sperren.

Supabase Auth verwaltet deine Zugangsdaten. Standardmäßig bleibt die Sitzung nur in diesem Browser-Tab gespeichert. Mit „Angemeldet bleiben“ wird sie auf diesem Gerät auch für spätere Besuche gespeichert. Beim Abmelden wird sie entfernt. Die App speichert dein Passwort nicht. Likes, Ansichten und Anfragen werden deinem Konto zugeordnet. Die Registrierung informiert dich darüber, ob eine E-Mail-Bestätigung erforderlich ist.

Der optionale Bildvergleich überträgt das ausgewählte generierte Personenbild und die berücksichtigten Tierfotos an Google Gemini. Die App speichert es nicht dauerhaft. Für die Verarbeitung bei Google gelten die Bedingungen des Anbieters. Die Oberfläche wird über GitHub Pages bereitgestellt; Tierbilder liegen im zugriffsgeschützten Supabase-Speicher.
